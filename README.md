# Code and Data for "A Likelihood Framework for Estimating Infection Efficiency in Plant Inoculation Experiments"

This repository contains the data and analysis code used to produce the
results and figures presented in:

**Rich, J. et al. "A Likelihood Framework for Estimating Infection Efficiency in Plant Inoculation Experiments"**

## Contents

- `data/` — Data used in the analyses.
- `figures.ipynb` — Jupyter notebook containing the analysis code used to
  generate the figures presented in the paper.

## Requirements

The analysis was performed using Python and Jupyter Notebook. The required
Python packages are imported in `figures.ipynb`.

A LaTeX installation is also required to reproduce the figures, as LaTeX
is used for mathematical typesetting.

## Reproducibility

To reproduce the figures presented in the paper:

1. Clone or download this repository.
2. Ensure that Python, Jupyter Notebook, and LaTeX are installed.
3. Open `figures.ipynb`.
4. Run the code cells from start to finish.

The notebook will load the data from the `data/` directory and reproduce the
analyses and figures presented in the manuscript.
